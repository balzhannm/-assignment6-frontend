## About this project
This is my beginner-level Assignment 6 project. It demonstrates jQuery selectors, effects, DOM manipulation and animations.

## How to open the project
1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Use the navigation menu to open each task.

## Pages
- `index.html` - Home page
- `selectors.html` - Task 0 and Task 1
- `effects.html` - Task 2, Task 3 and Task 4
- `dom.html` - Task 5, Task 6 and Task 7
- `animations.html` - Task 8, Task 9 and Task 10
- `project.html` - Task 11, Image Gallery mini project

## Technologies
- HTML
- CSS
- JavaScript
- jQuery 3.7.1 (included from the official CDN)

The project needs an internet connection to load jQuery and the sample images from their CDNs.
